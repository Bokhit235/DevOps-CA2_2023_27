# BATIR TCHAD — DevOps CA-2

Je souhaite développer un projet nommé BATIR TCHAD.

BATIR TCHAD est une application mobile et une plateforme web permettant aux citoyens tchadiens de signaler les infrastructures publiques dégradées afin que les autorités puissent intervenir rapidement.

Fonctionnalités principales :

Inscription et connexion des utilisateurs.

Création de profil utilisateur.

Signalement d'infrastructures avec photo, plusieurs images, description et géolocalisation GPS.

Catégories : routes, ponts, écoles, centres de santé, eau, marchés et autres infrastructures publiques.

Classification automatique des signalements par niveau de gravité : rouge, orange, jaune et vert.

Carte interactive affichant tous les signalements sur le territoire du Tchad.

Tableau de bord pour les autorités avec filtres par province, ville, catégorie et gravité.

Gestion des statuts : signalé, vérifié, en cours, résolu et rejeté.

Notifications par application, email et SMS.

Statistiques nationales par province, catégorie et statut.

Future intégration d'intelligence artificielle pour analyser les photos et détecter automatiquement les dégâts.

## Technologies

- Mobile : React Native
- Web : React.js
- Backend : Firebase ou Supabase
- Cartographie : Google Maps ou OpenStreetMap

## DevOps

Le projet comprend :

- Docker
- Kubernetes / Minikube
- Kubernetes Service
- Horizontal Pod Autoscaler (HPA)
- Prometheus
- Grafana
- Ansible
- GitHub
